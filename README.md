# 网页学英语（Edge 浏览器扩展）

浏览中文网页时，把网页上的**部分中文词替换为英文**，在真实阅读场景中边用边学。

> 仅替换**网页内容**。浏览器自身界面（菜单、地址栏、设置页等）属于浏览器 Chrome 层，任何扩展都无法修改。

---

## 一、安装

1. 在 Edge 地址栏输入 `edge://extensions` 并回车。
2. 打开左下角 **开发人员模式** 开关。
3. 点击 **加载解压缩的扩展**，选择本文件夹（含 `manifest.json` 的那个目录）。
4. 加载成功后，工具栏出现 "网页学英语" 图标。

> 使用打包文件：将 `网页学英语-Edge插件.zip` 解压到任意目录，再按上述第 3 步选择解压后的文件夹。

## 二、快速使用

- 点击工具栏图标：显示当前状态（开关 / 难度 / 比例 / 生词本数量），点 **详细设置** 进入设置页。
- 默认开启：**入门** 难度、**30%** 替换比例、内置核心词库 + 扩展词库。
- 被替换的词显示为橙色虚线下划线，**鼠标悬停可看到原中文**。
- **每次刷新页面，被替换的单词组合会变化**（随机种子），持续曝光更多词。
- **单击**替换出的英文词可**发音**；**双击**可**收藏到生词本**（在设置页可查看/导出）。

## 三、设置项

| 设置 | 说明 |
|---|---|
| 总开关 | 是否启用替换 |
| 学习难度 | 入门（搜索、登录、首页等最常用词）→ 进阶 → 高级（书面词）；等级越高替换的词越难 |
| 替换比例 | 同一网页内命中词按此比例替换，比例低更易读懂，比例高学得多 |
| 扩展词库 | 开启后使用内置 9.6 万词条离线词库（CC-CEDICT），生僻词也能翻译 |
| 悬停提示 | 悬停时显示原中文（默认开启） |
| 单击发音 | 点击替换出的英文词，用系统语音朗读 |
| 生词本 | 双击英文词收藏；设置页可查看、导出 CSV 复习 |
| 在线翻译 | 填入百度翻译 APPID 和密钥后，生僻词可在线兜底翻译（见下） |
| 自定义词表 | 每行一个词，格式 `中文=英文`，优先于内置词库 |
| 网站黑名单 | 每行一个域名，这些网站不替换（支持 `*.example.com`） |

> 修改设置后自动生效，无需重启浏览器。

## 四、在线翻译配置（可选，5 分钟）

内置离线词库覆盖绝大部分常用词；如需覆盖更长尾的生僻词，可免费接入百度翻译：

1. 打开 https://fanyi-api.baidu.com ，注册/登录百度账号。
2. 进入 **管理控制台 → 开发者信息**，申请开通 **通用文本翻译 API（标准版）**。
3. 获取 **APPID** 和 **密钥**（密钥只在申请成功后显示一次，请先复制保存）。
4. 在插件设置页 **在线翻译** 栏填入 APPID 和密钥并保存。

- **标准版完全免费、不限字符量**（每秒限 1 次请求），满足个人长期使用。
- 只有在线兜底翻译时，才会把个别生僻词发送到百度翻译服务器；其余全部在本地完成。

## 五、词库说明

| 词库 | 规模 | 来源 |
|---|---|---|
| 核心词库 | 940 词（入门/进阶/高级三级） | 手工整理，覆盖界面高频词 |
| 扩展词库 | 97,668 词条 | CC-CEDICT 开源词典（CC BY-SA 4.0，来源 https://www.mdbg.net/chinese/export/cedict/ ） |

> 释义已清洗：每个词取最常用义，去掉动词 "to " 前缀、括号注释、多义串（如 `测试→test`、`中心→center`），保证界面显示自然。

## 六、隐私说明

- 所有设置、词库、翻译缓存均存储在**本机**（浏览器扩展存储）。
- 替换过程完全在本地完成，不访问任何服务器。
- 仅当**开启在线翻译**且遇到离线词库未覆盖的生僻词时，才向百度翻译发送该词。

## 七、自测结果

- 单元测试：21/21 通过（词库匹配、等级过滤、比例确定性、防破碎替换、释义格式干净等）。
- 真实 Edge 实测：测试页 36 处替换正常；"帮助中心→Support Center"、"购物车"等复合词不破碎；悬停原中文正确；**双击收藏生词本成功写入**、设置页生词本列表/导出正常；动态加载内容可自动替换。

## 八、文件结构

```
extension-LearnEnglish/
├── manifest.json          # 扩展清单（MV3）
├── background.js          # 后台：在线翻译请求与签名
├── content/               # 替换引擎（DOM 遍历 + 动态监听 + 发音/生词本交互）
├── lib/
│   ├── dict-core.js       # 核心词库（三级 941 词）
│   ├── dict-ext.json      # 扩展词库（9.6 万词，离线）
│   └── matcher.js         # 匹配核心（最长匹配 + 比例 + 等级）
├── options/               # 设置页
├── popup/                 # 工具栏弹窗
└── icons/                 # 图标
```

## 九、常见问题

- **为什么浏览器界面不替换？** 扩展只能修改网页内容，浏览器自身界面不受扩展控制。
- **有些词没被替换？** 可能被替换比例筛掉（可调高比例）、在黑名单中、或属于更高难度等级（可调高难度）。
- **扩展更新后不生效？** 在 `edge://extensions` 点击该扩展的刷新按钮，或重新加载。
- **想卸载？** 在 `edge://extensions` 点击"删除"即可，所有本地数据随之清除。
